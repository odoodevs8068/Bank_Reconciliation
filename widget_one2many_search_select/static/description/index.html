Overview

    Overview

  • The One2Many Search & Select widget allows users to easily filter and select records in a One2Many field in Odoo 15. It provides an intuitive search input and multi-select functionality, improving usability for managing large datasets.

    Usage

    Follow these steps to use the widget effectively:

    1. Navigate to a form view with a One2Many field.
    2. Use the search bar to filter records by keywords.
    3. Select multiple records using the checkboxes provided.
    4. Click the "Revert Reconciliation" button to perform the desired operation on selected records.

    Facilities

    • Real-time search functionality within the One2Many field.
    • Multi-select option for batch operations.
    • Customizable notifications for successful or failed actions.
    • Responsive design for seamless integration with Odoo 15's interface.
  • User Can get Search And Select Faciltity in One2many by using [widget="one2many_search_select"]
